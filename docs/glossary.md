# Glossary

Short definitions of every term the curriculum uses, with where to learn more. Turn the ones you meet each day into flashcards: term on the front, definition and one example on the back.

| Term                                    | Definition                                                                                                                                   | Where                                                                      |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| **Anti-affinity**                       | A scheduling preference to put replicas of the same service on different nodes or zones, so one failure cannot take all of them down.        | [9](09-scale.md)                                                           |
| **ARP**                                 | The protocol that finds the MAC address for an IP address on the local network.                                                              | [F2](foundations/f2-networking.md)                                         |
| **Backoff (exponential)**               | Waiting longer after each failure (1s, 2s, 4s … capped) before retrying, so a crashing process does not hot-loop.                            | [8](08-provisioning-engine.md)                                             |
| **Bin-packing**                         | Scheduling that fills the fullest node that still fits, to use fewer machines. Opposite of spreading.                                        | [9](09-scale.md)                                                           |
| **Bind mount**                          | Making an existing directory or file appear at a second path. Docker volumes are bind mounts.                                                | [F1](foundations/f1-linux.md), [2](02-filesystems.md)                      |
| **Blob**                                | Any content-addressed object in a registry or content store: a layer, a config or a manifest.                                                | [6](06-images.md)                                                          |
| **Bounding set**                        | The capability ceiling for a process tree: no `execve` can ever grant a capability outside it.                                               | [4](04-security.md)                                                        |
| **Bridge**                              | A software L2 switch in the Linux kernel. Containers plug into one via veth pairs (`docker0`, `rh0`).                                        | [5](05-networking.md)                                                      |
| **BuildKit**                            | Docker's modern build engine: compiles a Dockerfile to a graph, caches every step by content, runs independent steps in parallel.            | [7](07-builds.md)                                                          |
| **Cache key**                           | A hash of everything that can change a build step's output. Same key, same result, so the step can be skipped.                               | [7](07-builds.md)                                                          |
| **Capability**                          | One slice of root's power (e.g. `CAP_NET_ADMIN`, `CAP_SYS_ADMIN`). Containers keep a small set.                                              | [4](04-security.md)                                                        |
| **cgroup**                              | A kernel mechanism that limits and measures the resources (CPU, memory, pids, I/O) a group of processes uses.                                | [3](03-cgroups.md)                                                         |
| **cgroup v1 / v2**                      | The legacy per-controller hierarchies vs the unified single tree. Modern systems use v2.                                                     | [3](03-cgroups.md)                                                         |
| **chroot**                              | Change one process's root directory. Escapable by root; containers use `pivot_root` instead.                                                 | [2](02-filesystems.md)                                                     |
| **CLONE_INTO_CGROUP**                   | A `clone3` flag that creates a child directly inside a cgroup, closing the window where it runs unlimited.                                   | [3](03-cgroups.md)                                                         |
| **Conntrack**                           | The kernel's table of tracked connections, which NAT uses to translate replies back.                                                         | [F2](foundations/f2-networking.md), [5](05-networking.md)                  |
| **Consensus**                           | Getting a group of machines to agree on one ordered log of decisions despite failures (Raft, Paxos).                                         | [F6](foundations/f6-distributed-systems.md)                                |
| **containerd**                          | The container daemon under Docker and Kubernetes: images, snapshots, and container lifecycle via shims.                                      | [F4](foundations/f4-docker-and-compose.md)                                 |
| **Control plane**                       | The part of a platform that decides what should run where (API, state, schedulers, controllers). The data plane runs it and carries traffic. | [8](08-provisioning-engine.md)                                             |
| **Copy-up**                             | Overlayfs copying a lower-layer file into the upper layer the first time it is written.                                                      | [2](02-filesystems.md)                                                     |
| **CPU quota / throttling**              | `cpu.max`: a budget of CPU time per period. Using it up early means waiting (being throttled) until the next period.                         | [3](03-cgroups.md)                                                         |
| **Desired vs observed state**           | What should be true (stored) vs what is true (discovered). A reconciler acts on the difference.                                              | [8](08-provisioning-engine.md)                                             |
| **Diff ID**                             | The sha256 of an uncompressed layer tar. Identifies layer content regardless of compression.                                                 | [6](06-images.md)                                                          |
| **Digest**                              | A content hash such as `sha256:ab12…`. Naming things by digest makes them immutable and verifiable.                                          | [6](06-images.md)                                                          |
| **Drain**                               | Removing an instance from traffic but letting in-flight requests finish before stopping it.                                                  | [8](08-provisioning-engine.md)                                             |
| **Edge proxy**                          | The load balancer where external traffic enters the platform and is routed to healthy instances.                                             | [5](05-networking.md)                                                      |
| **eBPF**                                | Small verified programs loaded into the kernel for networking, observability and security (used by Railway's private networking).            | [5](05-networking.md)                                                      |
| **Exit status 137 / 143**               | 128 + 9 (SIGKILL, often OOM) and 128 + 15 (SIGTERM).                                                                                         | [F1](foundations/f1-linux.md)                                              |
| **Fencing token**                       | A number that increases with every lease grant, so a stale lease holder's writes can be rejected.                                            | [F6](foundations/f6-distributed-systems.md)                                |
| **File descriptor**                     | A small integer a process uses to refer to an open file, pipe, socket or device.                                                             | [F1](foundations/f1-linux.md)                                              |
| **Firecracker / microVM**               | A minimal virtual machine monitor that boots in ~100 ms; VM isolation at container-like density.                                             | [9](09-scale.md)                                                           |
| **fork / execve / wait**                | Duplicate a process / replace its program / collect its exit status. How every process starts.                                               | [F1](foundations/f1-linux.md)                                              |
| **Health check (readiness / liveness)** | Readiness: may this instance receive traffic? Liveness: should it be restarted?                                                              | [8](08-provisioning-engine.md), [F5](foundations/f5-kubernetes.md)         |
| **Idempotent**                          | Safe to repeat: doing it twice has the same effect as once. Essential for retries.                                                           | [F6](foundations/f6-distributed-systems.md)                                |
| **Image config**                        | The JSON in an image with its defaults (env, cmd, user, workdir) and the list of diff IDs. Its digest is the image ID.                       | [6](06-images.md)                                                          |
| **Immutable deployment**                | A deployment never changes after creation; any change creates a new one. Enables history and rollback.                                       | [8](08-provisioning-engine.md)                                             |
| **Index (manifest list)**               | A multi-platform image entry pointing to one manifest per OS/architecture.                                                                   | [6](06-images.md)                                                          |
| **IPAM**                                | IP address management: handing out addresses without collisions.                                                                             | [5](05-networking.md)                                                      |
| **Lease**                               | A lock with an expiry that the holder must keep renewing.                                                                                    | [F6](foundations/f6-distributed-systems.md)                                |
| **Level-triggered**                     | Acting on the current difference between desired and observed state, not on individual events. Survives lost events.                         | [8](08-provisioning-engine.md)                                             |
| **Manifest**                            | The JSON that lists an image's config and layers by digest. Its digest pins an image exactly.                                                | [6](06-images.md)                                                          |
| **Masquerade (SNAT)**                   | Rewriting a container's source address to the host's on the way out.                                                                         | [5](05-networking.md)                                                      |
| **Mount namespace**                     | A private copy of the mount table, so a container's mounts are invisible to the host.                                                        | [1](01-namespaces.md), [2](02-filesystems.md)                              |
| **Namespace (Linux)**                   | A kernel feature that gives a process its own view of one resource: PIDs, mounts, network, hostname, IPC, cgroups, users.                    | [1](01-namespaces.md)                                                      |
| **no_new_privs**                        | A process flag that stops `execve` from ever granting more privilege (setuid binaries stop working).                                         | [4](04-security.md)                                                        |
| **OCI**                                 | The Open Container Initiative: specs for images, runtimes and registries that all tools implement.                                           | [6](06-images.md)                                                          |
| **OOM killer**                          | The kernel mechanism that kills a process when memory runs out, system-wide or inside a cgroup.                                              | [3](03-cgroups.md)                                                         |
| **Opaque directory**                    | An overlayfs directory marked so nothing from lower layers shows through.                                                                    | [2](02-filesystems.md)                                                     |
| **Overlayfs**                           | A union filesystem that stacks read-only lower directories under one writable upper directory.                                               | [2](02-filesystems.md)                                                     |
| **PID 1**                               | The first process in a PID namespace. Gets no default signal handling and must reap orphans.                                                 | [1](01-namespaces.md)                                                      |
| **pivot_root**                          | Swap the root mount of a mount namespace, so the old root can be detached completely.                                                        | [2](02-filesystems.md)                                                     |
| **Promotion**                           | Making a new deployment the one that receives traffic, after all its replicas are healthy.                                                   | [8](08-provisioning-engine.md)                                             |
| **Raft**                                | An understandable consensus algorithm with a leader and majority commits (used by etcd).                                                     | [F6](foundations/f6-distributed-systems.md)                                |
| **Reconciler / controller**             | A loop that repeatedly moves observed state toward desired state.                                                                            | [8](08-provisioning-engine.md)                                             |
| **Recreate deploy**                     | Stop the old version, then start the new one. Downtime, but never two writers on one volume.                                                 | [8](08-provisioning-engine.md), [11](11-capital-lab.md)                    |
| **Registry**                            | An HTTP service storing images as content-addressed blobs plus tags (Docker Hub, GHCR).                                                      | [6](06-images.md)                                                          |
| **Rendezvous hashing**                  | Rank nodes by hash(node, key); the top one owns the key. Removing a node only moves its own keys.                                            | [7](07-builds.md), [9](09-scale.md)                                        |
| **Rolling deploy**                      | Start the new version beside the old, wait for health, switch traffic, drain and stop the old.                                               | [8](08-provisioning-engine.md)                                             |
| **runc**                                | The reference OCI runtime: creates the namespaces, cgroups and root filesystem and execs the process.                                        | [1](01-namespaces.md), [F4](foundations/f4-docker-and-compose.md)          |
| **Scheduler**                           | Decides which node runs each workload: filter by hard constraints, score by preferences.                                                     | [9](09-scale.md)                                                           |
| **seccomp**                             | A kernel filter that restricts which system calls a process may make.                                                                        | [4](04-security.md)                                                        |
| **setns / unshare / clone**             | Join an existing namespace / create new ones for the caller / create a child in new ones.                                                    | [1](01-namespaces.md)                                                      |
| **Shim**                                | A small per-container supervisor that owns the container's stdio and exit status, so the daemon can restart.                                 | [8](08-provisioning-engine.md), [F4](foundations/f4-docker-and-compose.md) |
| **Signal**                              | An asynchronous notification to a process (SIGTERM, SIGKILL, SIGINT, SIGCHLD…).                                                              | [F1](foundations/f1-linux.md)                                              |
| **Snapshotter**                         | containerd's component that prepares root filesystems from layers (overlayfs being the common one).                                          | [2](02-filesystems.md)                                                     |
| **Split brain**                         | Two parts of a partitioned system both acting as the authority. Prevented by majorities and fencing.                                         | [F6](foundations/f6-distributed-systems.md)                                |
| **Subreaper**                           | A process that adopts orphaned descendants instead of PID 1 (`PR_SET_CHILD_SUBREAPER`); shims use it.                                        | [1](01-namespaces.md)                                                      |
| **System call**                         | A request from a program to the kernel (open, read, fork, mount…).                                                                           | [F1](foundations/f1-linux.md)                                              |
| **Thundering herd**                     | Many clients acting at once (e.g. redeploying after a base image update), overloading a shared system.                                       | [F6](foundations/f6-distributed-systems.md)                                |
| **TTL**                                 | Time to live: how long a DNS answer (or cache entry) may be reused.                                                                          | [F2](foundations/f2-networking.md)                                         |
| **Upper / lower directory**             | Overlayfs's writable per-container layer and the read-only image layers beneath it.                                                          | [2](02-filesystems.md)                                                     |
| **veth pair**                           | A virtual Ethernet cable: two interfaces, whatever enters one leaves the other.                                                              | [5](05-networking.md)                                                      |
| **Volume**                              | Storage that outlives a container, mounted into it. Single-writer unless the storage supports sharing.                                       | [11](11-capital-lab.md)                                                    |
| **Whiteout**                            | A layer entry meaning "this file was deleted": `.wh.<name>` in a tar, a 0/0 character device in overlayfs.                                   | [2](02-filesystems.md)                                                     |
| **Work queue**                          | A queue that never gives one key to two workers at once and coalesces repeated events.                                                       | [8](08-provisioning-engine.md)                                             |
| **Zombie**                              | A process that has exited but whose parent has not yet collected its exit status.                                                            | [F1](foundations/f1-linux.md)                                              |
